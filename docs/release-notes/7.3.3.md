# Nishizumi Paints 7.3.3

Release date: 2026-08-13

## Nothing falls off the bottom of the window anymore

7.3.0 to 7.3.2 added the iRacing UI car previews panel, the automatic install preference, and the Install update button. The General tab grew past what the window shows, and on smaller screens the last options were simply cut off with no way to reach them.

From 7.3.3 every tab is a scrollable page. When a tab is taller or wider than the window, a scrollbar appears on that tab and the rest of the content is one scroll away.

## How it behaves

- A tab that fits looks exactly like before: no scrollbar, and panels that used to stretch to the bottom of the window still stretch.
- A tab that does not fit gets a scrollbar on the side, and a horizontal one at the bottom if the window is narrower than the tab.
- The scrollbars come and go on their own, including when an option is toggled that shows or hides a panel, such as `Show activity`, `Show TP monitor`, or the custom iRacing Documents folder.
- The mouse wheel scrolls whichever tab is under the pointer. Lists that scroll on their own — the driver table, the activity log, the collection list — keep the wheel while the pointer is over them.
- `Shift` and the mouse wheel scroll sideways.

## Window size

- The window opens at 1440x760 when the screen has room for it, and shrinks to fit the screen when it does not. A 1366x768 laptop now opens at 1326x688 instead of a window wider than the screen.
- The minimum window size is 960x560, down from 1220x620. Making the window that small no longer hides anything, it just means more of the tab is scrolled.

## Session tab

The driver list asks for 12 rows instead of 18. It still grows to fill whatever space the tab has, so on a normal window the table looks the same. The smaller request is only how far the table may give room back before the Session tab starts scrolling.

## Validation

- 25 new tests cover the page geometry (fits, too tall, too wide, exact fit, rounding), the window size chosen for large, laptop, and tiny screens, and the mouse wheel translation for Windows notches, fast wheels, precision wheels, and X11 wheel buttons.
- Widget-level tests build a real notebook tab and check that a page which fits fills the view with no scrollbar, that options below the window become reachable by scrolling, that content shown or hidden later updates the scrollbar, that the wheel scrolls the page but leaves a scrolling list alone, and that a tab measured while hidden is corrected when it is shown.
- Full suite: 108 tests, all passing.
